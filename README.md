# くらべてえらぶ

静的サイト。`public/` 配下をそのまま Cloudflare Pages で配信する(ビルドコマンドなし、出力ディレクトリ `public`)。

## 記事を更新したとき
記事を修正したら、その記事の1行目のメタ情報に `"updated":"YYYY年M月D日"` を入れて更新日を書き換える(記事ページに「記事更新:」と表示され、構造化データの dateModified にも入る)。価格を取り直したときだけ `date`(公開・価格確認)も更新する。

## よくある質問(FAQ)を足すとき
記事の1行目のメタ情報に `"faq":[{"q":"質問","a":"答え"}]` を入れる。本文の「出典」の前に「よくある質問」が出て、FAQPageの構造化データも出力される。答えは記事本文・出典にある事実だけで書く。追加したら `updated` も更新する。
測定の見方は `notes/measurement.md`。

## 価格比較枠・自動FAQ(2026年10月24日〜)
- 記事冒頭の結論の下に、`eye.items` の全商品を楽天の価格の安い順で並べた枠が自動で出る(高料率の商品に寄せず、読者が選べるようにするため)。「記事のおすすめ」表示はメタ情報に `"pick":"キー"` を書いた記事だけ。
- `faq` がない記事には、タイトルの問い＋結論文と、楽天価格(確認日つき)からFAQを自動で作る(新しい事実は足さない)。
- 構造化データの ItemList に Product/Offer(価格・楽天リンク)を入れ、llms.txt にも各記事の楽天価格を載せる。
