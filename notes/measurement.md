# 週次の測定メモ(AI検索の時代に合わせた見方)

背景: AI要約だけで検索を終える人が増えている(NTTドコモ モバイル社会研究所の調査では64%、2025年11月実施)。
クリックされない前提で、「引用される→指名・型番検索→購入直前にクリック」の流れを測る。

## 毎週同じ日に記録する(月曜の朝のチェックで)
| 指標 | 見る場所 | 見方 |
|---|---|---|
| 登録済みページ数 | Search Console「ページ」 | 10を超えるまでは測定そのものが難しい |
| 表示回数・クリック数・クリック率 | Search Console「検索パフォーマンス」 | 表示が増えてもクリック率が下がるなら、AI要約の影響を疑う |
| 型番を含む検索語 | 同上(クエリ) | 「A B 違い」型の検索が増えているか |
| AI経由の参照 | Cloudflare Web Analytics の参照元 | chatgpt.com、perplexity.ai、copilot系などが出るか |
| 楽天リンクのクリック数 | 楽天アフィリエイトの管理画面 | 記事ごとの強弱を見る(クリックが出る記事を増やす) |

## 判断ルール
- 登録10ページ超 かつ 1か月分のデータが貯まるまでは、方針を大きく変えない。
- 開始から3か月(2027年1月上旬)で月1,000円未満なら止める(撤退ライン)。
- 3か月の時点で「クリックはあるが購入が出ない」「表示はあるがクリックが出ない」のどちらかを切り分けてから、動画・楽天ROOMなど別の入口を足す。

## サイトに入れた対策(2026-10-19)
- 記事のメタ情報に `faq` を書くと、「よくある質問」を本文に出し、FAQPageの構造化データも出す。内容は記事本文と出典にある事実だけ。
- 記事の構造化データに、比べている商品(ItemList)を追加。トップにWebSite・Organizationを追加。
- sitemapのlastmodを、記事ごとの実際の公開日・更新日にした。
- `public/llms.txt` を自動生成(AI向けの案内。効果はまだ確認されていない)。
