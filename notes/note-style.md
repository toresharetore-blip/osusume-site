# note記事の書き方ルール(2026-11-23 本人指摘を受けて)

## 本人の指摘
1. 注釈は一番後ろに書く
2. 強調表示が使えない場合は、記号で各項目を見やすくする
3. 改行を工夫する
4. AIが書いたと思われる特徴を分析して直す
5. 他の記事を参考にする

## AIらしさの分析(記事3 初版)と直し方
| 特徴 | 例 | 直し方 |
|---|---|---|
| 機械的な見出し | 「結論(4行)」「数字で見るポイント」 | 読者の言葉で書く(「まず結論」「買う前に知っておきたい3つのこと」) |
| 書き手の姿がない | いきなり結論から | 冒頭2〜3行で、迷う理由に寄り添ってから本題へ |
| 文末が「です」で均一 | 全文「〜です。」 | 体言止め・問いかけ・「〜なら」を混ぜる |
| 括弧と矢印の多用 | 「(54,900円)」「→」 | 1行1情報にし、矢印は▶に統一して使いすぎない |
| ※注釈が冒頭に重なる | ※実体験ではなく…※PR… | 冒頭はPR表記1行だけ。出典・確認日・注意は末尾の〔注意事項〕にまとめる |
| ｜区切りの表 | 7列の横長テキスト表 | noteでは表が崩れるので、機種ごとに【機種名】＋2行の縦型にする |
| 1文が長い | 「〜で、〜なので、〜です」 | 1文1〜2行で改行し、段落の間に空行 |

## 参考にした記事
- mybest「回転式チャイルドシートのおすすめ」: 導入文で読者の迷いに共感→PR表記→本文→末尾に注意書き(売上還元・価格変動)。PR表記は導入文の直後、注意書きは末尾。

## 決めた型
1. タイトル(長すぎない。記号は｜1つまで)
2. 〔PR〕表記1行(ステマ規制のため冒頭に置く。末尾にも再掲)
3. 導入2〜3行(読者の迷い→この記事でわかること→実体験ではない旨)
4. ■ 見出し / ▶ 答え / ✓ チェック項目 / 【】 商品名 / --- 区切り
5. FAQは Q. / A.
6. 末尾に〔注意事項〕(適合確認・出典・確認日・価格変動・PR)
